# 売掛×買掛 期日アラート セットアップ手順

お読みいただきありがとうございます。5分でセットアップ完了します。

## 用意するもの
- Googleアカウント（無料）
- 通知先：**Slack の Incoming Webhook URL**、または **LINE公式アカウントのアクセストークン＋あなたのuserId** のどちらか

---

## 手順

### 1. テンプレをコピー
配布された「テンプレのコピーURL」を開き、**「コピーを作成」** を押します。あなたのGoogleドライブに複製されます（以降は複製したファイルを使います）。

### 2. 初回セットアップ
コピーしたスプレッドシート上部メニューの **「期日アラート」→「初回セットアップ」** を押します。
- 初回のみGoogleの権限承認画面が出ます。あなた自身のアカウントで承認してください（このスクリプトはあなたのシートとあなたの通知先にのみアクセスします）。
- 「取引一覧」「設定」「送信ログ」の3シートが自動で作られます。

### 3. 通知先を設定
**「設定」シート**に、使う通知先を記入します。

| 項目 | 記入例 |
|---|---|
| 通知先(slack/line) | `slack` または `line` |
| Slack Webhook URL | （Slackを使う場合）`https://hooks.slack.com/services/...` |
| LINEアクセストークン | （LINEを使う場合）Messaging APIのチャネルアクセストークン |
| LINE userId(カンマ区切り) | （LINEを使う場合）通知を受け取るuserId |
| 送信オフセット(買掛の期日前日数) | `7,3,1,0`（支払期日の7日前・3日前・1日前・当日に通知）|
| 売掛の督促(ON/OFF) | `ON` |
| 実行時刻(0-23) | `8`（毎朝8時台に自動実行）|
| 買掛テンプレ / 売掛テンプレ | 通知文面。`{取引先}{金額}{期日}{残り日数}` が差し込まれます |

### 4. 取引を入力
**「取引一覧」シート**に、監視したい取引を入力します。

| 種別 | 取引先 | 金額 | 期日 | 済 | メモ | 有効 |
|---|---|---|---|---|---|---|
| 買掛 | 仕入先A | 50000 | 2026-07-31 | ☐ | | ☑ |
| 売掛 | 取引先B | 80000 | 2026-07-20 | ☐ | | ☑ |

- **種別**：`買掛`＝あなたが支払う／`売掛`＝あなたが受け取る（ドロップダウン）
- **済**：入金/支払が完了したらチェック → 以後通知しません
- **有効**：チェックが入っている行だけ監視します

### 5. テスト送信
メニュー **「期日アラート」→「テスト送信」** を押し、設定した通知先にテストメッセージが届けば設定完了です。

### 6. 以降は自動
毎日「実行時刻」に自動で期日をチェックし、条件に合う取引だけ通知します。
すぐ試したいときは **「今すぐ実行」** を押してください。

---

## 通知の届き方
- **買掛**：支払期日の N日前（設定した日数）に「【支払】…残りN日」が届きます。
- **売掛**：入金予定日を過ぎても未入金なら「【入金遅延】…期日を過ぎています」が届きます。
- 同じ通知は一度だけ。完了したら「済」にチェックしてください。

## よくある質問
- **Q. 通知が来ない** → 「設定」の通知先・トークンを確認し、「テスト送信」で疎通を確認してください。「有効」チェックと「済」未チェックもご確認を。
- **Q. 通知を止めたい** → 対象行の「有効」チェックを外す、または行を削除。
- **Q. 文面を変えたい** → 「設定」の買掛テンプレ/売掛テンプレを編集してください。

不具合・ご質問はショップのお問い合わせからご連絡ください。
