# スプシ期限リマインダー セットアップ手順書

スプレッドシートに入力した「期限つきの用事」を、期限が近づいたら **LINE / Slack に自動通知**するツールです。プログラミングの知識は不要。**コピーして数か所入力するだけ**で使えます。

> **最短の流れ（Slackの場合）**: ①テンプレをコピー → ②「初回セットアップ」を押す → ③Webhook URLを1つ貼る。これだけで動きます。

### この手順書について
- 対象: スプシ期限リマインダー v1（LINE / Slack 対応）
- 画像（各 `![...]`）は実際の画面キャプチャです。お使いの環境やサービス側の更新で見た目が多少変わることがあります。
- うまくいかないときは「**5. つまずきポイント（FAQ）**」→ それでも解決しなければ購入ページからお問い合わせください。

---

## 0. このツールでできること（ゴール）

- スプレッドシートに「期限日・件名・本文」を書いておくと、**7日前・1日前・当日**（変更可）に自動でLINE/Slackへお知らせ。
- 期限が過ぎたら「超過」通知（任意）。
- 一度送った通知は**二重に送りません**（安心設計）。

**完成イメージ（テスト通知が届いた画面）:**

![ゴール：LINE/Slackにテスト通知が届いた画面](manual-assets/goal.png)

所要時間の目安: **Slack 約5分 / LINE 約10〜15分**（LINEは初回のみ公式アカウント作成が必要）

## 1. 事前に決めること

- 通知を受け取る先を **Slack か LINE のどちらか**に決めます。
  - **Slack**: すでにSlackを使っているチーム向け。設定が一番かんたん（URLを1つ貼るだけ）。
  - **LINE**: 普段LINEで受け取りたい個人・小規模向け。初回だけ公式アカウント作成の手間があります。

---

## 2. 【共通】テンプレをコピー → 初回セットアップ

### ステップ2-1: テンプレをコピー
配布された**テンプレのスプレッドシートを開き**、`ファイル > コピーを作成` で自分のドライブにコピーします。以降は**コピーした自分のシート**で作業します。

![ファイル＞コピーを作成](manual-assets/common-01.png)

### ステップ2-2: 「初回セットアップ」を押す
コピーしたシートを開くと、メニューに「**リマインダー**」が増えています（表示されないときは一度ページを再読み込み）。
`リマインダー > 初回セットアップ` をクリックします。

![リマインダー＞初回セットアップ](manual-assets/common-02.png)

### ステップ2-3: 認証（初回だけ）
「このドキュメントに添付されたスクリプトを実行するには、あなたの許可が必要です」と出たら **OK** →
アカウントを選択 → 「このアプリはGoogleで確認されていません」と出たら **詳細 > （プロジェクト名）に移動** → 権限を確認して **許可**。
（自作スクリプトのため、この警告は正常です）

![認証が必要です ダイアログ](manual-assets/common-03.png)

### ステップ2-4: シートが用意される
`リマインド一覧` `設定` `送信ログ` の3シートが自動で作られます。この時点ではまだ通知先が未設定なので、
「**シートを準備しました。『設定』シートに通知先を入力してから、メニュー→テスト送信 を押してください**」という**案内が出れば成功**です（エラーではありません）。**OK** を押します。

![初回セットアップ後の案内アラート](manual-assets/common-04.png)

`リマインド一覧` の「有効」列はチェックボックスになっており、記入例が1行入っています。

![リマインド一覧（チェックボックス＋記入例）](manual-assets/common-05.png)

## 3-A. 【Slack編】通知先の設定（約2分）

### ステップ3A-1: Slack Incoming Webhook を作る
1. ブラウザで Slack にログインし、Incoming Webhook を追加します（Slackの `App管理 > Incoming Webhooks > Slackに追加`）。
2. 通知を送りたい**チャンネルを選択**して「**Webhook URLを追加**」。
3. 発行された `https://hooks.slack.com/services/...` の **URLをコピー**します。

![SlackのWebhook URL発行画面](manual-assets/slack-01.png)

### ステップ3A-2: 設定シートに貼る
`設定` シートで:
- 「通知先(slack/line)」を **slack**（プルダウンから選択）
- 「Slack Webhook URL」に、コピーしたURLを**貼り付け**

![設定シート（Slack）](manual-assets/slack-02.png)

### ステップ3A-3: テスト送信
`リマインダー > テスト送信` をクリック → **Slackにテスト通知が届けば完了**です。

![Slackにテスト通知が届いた](manual-assets/slack-03.png)

## 3-B. 【LINE編】通知先の設定（約10〜15分・初回のみ）

> **重要**: かつての「LINE Notify」は**2025年3月で終了**しました。現在は下記の **LINE Messaging API** を使います。無料枠は**月200通程度**なので、送りすぎに注意してください（オフセットを絞る等）。

### ステップ3B-1: LINE Developers にログイン
[developers.line.biz/console](https://developers.line.biz/console/) を開き、「**LINEアカウント**」でログインします。

![LINE Developers ログイン](manual-assets/line-01.png)

### ステップ3B-2: プロバイダーを作成
「Create（新規プロバイダー作成）」→ 名前（例: あなたの屋号や名前）を入力して作成。

![プロバイダー作成](manual-assets/line-02.png)

### ステップ3B-3: Messaging APIチャネルを作成
「**Messaging API**」チャネルを作成します。チャネル名・説明・カテゴリなどを入力して作成（**LINE公式アカウントが自動で作られます**）。

![Messaging APIチャネル作成](manual-assets/line-03.png)

### ステップ3B-4: アクセストークンを発行
チャネルを開き、「**Messaging API**」タブ →「**チャネルアクセストークン（長期）**」の **発行** を押してトークンを表示・コピー。

![チャネルアクセストークン発行](manual-assets/line-04.png)

### ステップ3B-5: あなたのユーザーIDを取得
「**チャネル基本設定**」タブ →「**あなたのユーザーID**」（`U` から始まる文字列）を**コピー**。

![あなたのユーザーID](manual-assets/line-05.png)

### ステップ3B-6: Botを友だち追加（必須）
「Messaging API」タブの**QRコード**を、あなたのスマホのLINEで読み取り、**この公式アカウントを友だち追加**します。
（友だちでないと通知が届きません）

![QRで友だち追加](manual-assets/line-06.png)

### ステップ3B-7: （任意）応答メッセージをオフ
通知専用にするなら、LINE Official Account Manager の「応答設定」で**応答メッセージをオフ**にすると、こちらから送った時に自動返信が返りません。

### ステップ3B-8: 設定シートに貼る
`設定` シートで:
- 「通知先(slack/line)」を **line**（プルダウン）
- 「LINEアクセストークン」に発行したトークンを**貼り付け**
- 「LINE userId(カンマ区切り)」に、コピーしたユーザーID（`U...`）を**貼り付け**

![設定シート（LINE）](manual-assets/line-07.png)

### ステップ3B-9: テスト送信
`リマインダー > テスト送信` → **LINEにテスト通知が届けば完了**です。

![LINEにテスト通知が届いた](manual-assets/line-08.png)

## 4. リマインドの書き方（`リマインド一覧`）

| 列 | 入れるもの | 例 |
|---|---|---|
| 期限日 | 通知の基準日 | 2026/07/31 |
| 件名 | 用事の名前 | 請求書送付 |
| 本文 | 通知メッセージ。差し込み可 | `{件名} の期限は {期限日}（残り{残り日数}日）です` |
| 有効 | チェックで有効 | ☑ |
| 送信状態 | （自動）送信済みの記録 | -7 0 |
| 最終送信日時 | （自動） | 2026-07-24 08:00 |
| メモ | 自由記入 | |

- **差し込みタグ**: `{件名}` `{期限日}` `{残り日数}` が本文に使えます。
- **いつ送るか**は `設定` の「送信オフセット」で変更（例 `7,1,0` = 7日前・1日前・当日）。
- **実行時刻**は `設定` の「実行時刻(0-23)」で変更（既定8時）。

## 5. つまずきポイント（FAQ）

- **メニュー「リマインダー」が出ない** → ページを再読み込み。数秒待つと表示されます。
- **認証で警告が出る** → 自作スクリプトのため正常です。「詳細 > 移動 > 許可」で進めてください。
- **通知が来ない（Slack）** → Webhook URLの貼り間違い/チャンネル権限を確認。`テスト送信` で切り分け。
- **通知が来ない（LINE）** → ①Botを**友だち追加**したか ②トークン/ユーザーIDの貼り間違い ③無料枠（月200通）超過、を確認。
- **同じ通知が二重に来る?** → 来ません。送信済みは「送信状態」列に記録され再送しません。
- **LINEの無料枠が心配** → 「送信オフセット」を `1,0` などに絞る/対象行を減らすと消費を抑えられます。

---

## 6. 自動実行について

「初回セットアップ」で**毎日1回（既定8時）自動チェック**するようになっています。パソコンを開いていなくても、Googleのサーバー側で動きます。停止したい場合は `設定` の対象行の「有効」チェックを外すか、行を削除してください。
