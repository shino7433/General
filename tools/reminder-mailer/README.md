# スプシ期限リマインダー（開発メモ）

スプレッドシートの期限データを LINE / Slack に自動通知するGASツール。設計書: `../../docs/superpowers/specs/2026-07-13-スプシ期限リマインダー-design.md`。

## 構成
- `core.js` — 純粋関数（`node --test core.test.js` でテスト）
- `main.js` — GAS結合部（テンプレのバインドスクリプトに配置。`core.js`→`main.js` の順に連結 or 2ファイルで貼付）
- `手順書.md` — 買い手向けセットアップガイド原本

## GAS配置
1. テンプレ用スプレッドシートの拡張機能→Apps Script。
2. `core.js` と `main.js` の中身を貼付（1ファイル連結でも2ファイルでも可。GASは全.gsがグローバル共有）。
3. スプレッドシートを再読み込み→メニュー「リマインダー」→「初回セットアップ」。

## データモデル
- リマインド一覧: A期限日/B件名/C本文/D有効/E送信状態/F最終送信日時/Gメモ
- 設定: 通知先/Webhook/LINEトークン/userId/オフセット/超過/上限/差出人名
- offsetLabel: `-N`（N日前）/`0`（当日）/`超過`
