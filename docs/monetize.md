# 広告・アフィリエイト手順書

マイクロツール([apps.md](apps.md))の収益化手順。時系列に「登録 → つなぎ広告 → AdSense審査 → 最適化」の順で進める。

## 全体フロー

```
Phase 0〜1前半: ASP登録(即日) + 忍者AdMax設置(審査なし・即収益化)
Phase 1:        コンテンツが揃ったらAdSense申請(審査 数日〜4週間)
Phase 1〜2:     AdSense合格 → 忍者AdMaxから差し替え → 配置最適化
常時:           文脈に合うページにだけアフィリリンク設置
```

## 1. ASP登録(無料・即日)

| ASP | 審査 | 特徴 |
|---|---|---|
| [A8.net](https://www.a8.net/) | **入会審査なし**・5分で登録 | 国内最大手。サイトかSNSアカウントがあれば登録可([手順](https://hitodeblog.com/a8-net-tukaikata)) |
| [もしもアフィリエイト](https://af.moshimo.com/) | サイト登録時に品質確認あり(独自コンテンツ5記事相当でほぼ通る) | **W報酬制度で通常報酬+12%**、振込手数料無料。Amazon・楽天ともここ経由で提携するのが効率的 |

手順:
1. A8.netにメールアドレスで仮登録 → 基本情報・サイト情報・振込口座を入力して完了
2. ツールサイトに5ページ相当(ツール+解説文)が揃ったら、もしもにサイト登録
3. もしも経由でAmazonアソシエイト・楽天アフィリエイトに提携申請

## 2. つなぎ広告: 忍者AdMax(審査なし)

AdSense合格までの期間も収益ゼロにしないための暫定枠。

- **審査不要・登録即日で広告配信可能**([解説](https://www.takaibiki.com/ninja-admax/))
- クリック単価はAdSenseより大幅に低いため、あくまで一時利用
- 設置: 管理画面で広告枠を作成 → 発行タグをツールページに貼る
- AdSense合格後は速やかに差し替える

## 3. AdSense申請(本命)

### 申請前チェックリスト(審査対策)

- [ ] **独自ドメインで運用している**(サブドメイン・無料ブログURLでは申請不可)([2026年版ガイド](https://www.tsuzukiblog.org/google-adsense-screening/))
- [ ] プライバシーポリシー設置(Cookie・広告利用の記載を含む。**必須**)
- [ ] 運営者情報・問い合わせフォーム(またはメールアドレス)設置
- [ ] 独自コンテンツが揃っている: ツール3本以上+各ツールの解説文+関連コラム数本(合計10ページ規模が目安)
- [ ] 全ページがスマホで正常表示される
- [ ] [AdSenseプログラムポリシー](https://adsense.google.com/intl/ja_jp/start/)違反コンテンツがない(著作権物・アダルト・誤情報など)
- [ ] 申請中も忍者AdMaxは外す(他社広告があると審査に不利という報告が多いため、審査期間中のみ非表示にする)

### 申請手順

1. [AdSense](https://adsense.google.com/)にGoogleアカウントでログイン → サイトURL・支払い先情報を入力
2. 発行されるAdSenseコードをサイトの`<head>`に設置
3. 「審査をリクエスト」 → 結果待ち(**数時間〜4週間**。1ヶ月かかる場合もある)
4. 不合格の場合: 理由(ポリシー/コンテンツ量)を確認 → 解説文の追加・ページ品質改善をして**2週間以上あけて再申請**

## 4. 合格後の運用

1. まず**自動広告**で配信開始(手間ゼロ)
2. 1〜2ヶ月データを取り、CTR/収益の低い配置を手動調整(ツールの結果表示直下・コンテンツ末尾が定石)
3. 広告過多にしない: ツールの使い勝手を壊すとリピートとSEOを失う(1画面に広告1〜2枠まで)

### 遵守事項(アカウント停止防止)

- **自己クリック・クリック誘導は厳禁**(「広告をクリックしてね」等の文言も違反)
- 広告とコンテンツを誤認させる配置をしない(ボタンの直上など)
- アフィリリンクには「PR」「広告」表記を入れる(**景品表示法のステマ規制対応・2023年10月〜義務**)
- Amazonアソシエイトは規定の表記(「Amazonのアソシエイトとして、当メディアは適格販売により収入を得ています」)をサイトに掲載

## 5. アフィリエイトリンクの設置方針(ついで運用)

- 記事を量産しない。**ツールの利用文脈に自然に合う商材だけ**設置する
  - 例: 積立シミュレーター → 証券口座開設(A8.netに案件あり)/ 投資書籍(Amazon)
  - 例: 画像圧縮ツール → レンタルサーバー・ストレージ
- 成果が出た組み合わせだけ月次レビューで確認し、出ないものは放置(改善に時間を使わない)

## 収益の目安(KPI連動)

| 収益源 | レート | 月5,000円に必要な規模 |
|---|---|---|
| AdSense | 0.2〜0.5円/PV | 1〜2.5万PV/月(ツール5〜10本合算で狙う) |
| 忍者AdMax | AdSenseの1/3〜1/5程度 | つなぎのため期待しない |
| アフィリエイト | 案件単価500〜10,000円/成約 | 月1〜2成約(文脈が合えば少PVでも発生する) |
