# マイクロWebツール戦略(柱2・並走)

1機能のWebツールをClaudeで量産し、広告で資産収入を作る。同時に開発代行([freelance.md](freelance.md))のポートフォリオを兼ねる。

## 1. 基本方針 — 「ニッチ×圧倒的シンプル」

参考モデルからパクる要素:

| 参考 | パクる要素 |
|---|---|
| 文字数カウントメモ(広告収入累計700万円超) | 1機能に絞り余計な機能をつけない。「◯◯したい」という具体ニーズに直球で応える([事例分析](https://shiftb.dev/articles/indie-dev-success-stories)) |
| Pomofocus(収益の8割が広告) | ブラウザ完結・サーバー不要・ページ内広告([収益化ロードマップ](https://shiftb.dev/articles/indie-dev-monetization)) |
| オプチャグラフ(月6〜8万PVで月2万円) | ニッチデータ/計算の可視化で検索を独占([開発ルーティン](https://zenn.dev/uzuprg/articles/8b83ee58fc45bd)) |
| 成功15事例の共通点 | **87%が大手の参入しないニッチ市場**を選択 → 選定基準に採用 |

**収益の現実**: AdSense ≒ 0.2〜0.5円/PV。月1万円 = 2〜5万PV。1本のホームランを狙わず、**5〜10本のポートフォリオで合算達成**する(宝くじを複数枚持つ発想)。

## 2. ネタ選定基準(ideas.mdの評価軸)

| 軸 | 基準 |
|---|---|
| 検索需要 | 「◯◯ 計算」「◯◯ ツール」で月間検索がある(Googleサジェスト・ラッコキーワードで確認) |
| 競合強度 | 検索上位が企業サイト・完成度の高いツールで埋まっていたら避ける。古い・使いにくいツールしかない領域が狙い目 |
| 制作コスト | Claudeで2〜4時間以内に作れる(クライアントサイド完結が原則) |
| 収益親和性 | 広告を置ける滞在時間があるか、文脈に合うアフィリ商材があるか |
| 独自性 | 自分の知見(投資・トレーディング)を活かせるものは優先度+1 |

## 3. 技術構成(全ツール共通・ランニングコスト0円)

```
静的サイト(HTML/CSS/JS、必要ならReactをCDNなしでビルド)
├─ ホスティング: Cloudflare Pages(無料・独自ドメイン対応)
├─ ドメイン: 1本の独自ドメイン配下にパスで並べる
│    例: example.com/fukuri/(複利計算)、example.com/eigyobi/(営業日計算)
│    → AdSense審査・ドメイン評価をサイト全体で共有できる
├─ 計測: GA4 + Search Console(無料)
└─ 収益: AdSense(合格後) / 忍者AdMax(つなぎ) / アフィリリンク → monetize.md
```

原則:
- **クライアントサイド完結**(サーバー処理なし)= 運用費ゼロ・保守ゼロ
- 1ドメインに集約(サブディレクトリ方式)。ツールごとにドメインを取らない
- リポジトリはGitHubで管理し、pushで自動デプロイ(Cloudflare Pages連携)

## 4. 制作ワークフロー(1本あたり2〜4時間)

1. [ideas.md](ideas.md)から候補を選ぶ(評価表の上位から)
2. 検索需要の裏取り: Googleサジェスト・関連キーワードを確認し、ページタイトル/H1に入れる検索語を決める
3. Claudeに実装依頼(機能+SEO要件+下のチェックリストをまとめて渡す)
4. 自分で動作確認(スマホ表示・主要ブラウザ)
5. デプロイ → Search Consoleにサイトマップ送信
6. X等で1回だけ告知(初期インデックス促進)。以降は放置し、月次レビューでPV確認

## 5. リリースチェックリスト(全ツール共通)

- [ ] タイトル・H1・meta descriptionに狙う検索語が入っている
- [ ] スマホ表示が崩れない(利用の過半はスマホ)
- [ ] 使い方説明+関連知識の解説文をページ下部に設置(AdSense審査対策・SEO用の独自コンテンツ)
- [ ] OGP画像設定(SNSシェア時の見栄え)
- [ ] GA4計測タグ設置
- [ ] プライバシーポリシー・運営者情報・問い合わせ先へのリンク(サイト共通ページ。**AdSense必須要件**)
- [ ] 広告枠 or アフィリリンクの設置([monetize.md](monetize.md)の規約に従う)
- [ ] 計算ロジックの検算(投資系ツールは特に。誤った数字は信用を失う)

## 6. 免責事項(投資系ツール共通)

投資・税金系の計算ツールには必ず以下を明記する:
- 計算結果は概算であり、正確性を保証しない
- 投資判断・税務申告は自己責任であり、必要に応じて専門家に相談すること
- 特定の金融商品の勧誘・推奨ではないこと
