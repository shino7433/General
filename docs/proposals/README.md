# 提案ドラフト ワークスペース

クラウドワークス等で見つけた案件に対する「応募判断 → 提案文 → 結果」を回すための作業場。
[crowdworks.md](../crowdworks.md)のプレイブックを実案件に適用する場所。

## 運用ループ

```
1. 自分: CWアカウントで新着を検索(検索条件は crowdworks.md §2)
2. 自分: 気になる案件の「タイトル・報酬・納期・本文(・提案数)」をClaudeに貼る
3. Claude: 以下をまとめて返す
   - Go/No-Go判断(crowdworks.md §2の狙い目シグナル + freelance.md §4の基準で)
   - 提案文ドラフト(型A/B/C の使い分けは crowdworks.md §4)
   - 見積り(freelance.md §7の単価表ベース)+想定実稼働
   - 勝負案件なら型C用の動くデモ(プロトタイプ)まで制作
4. 自分: ドラフトを自分の言葉に調整して送信
5. 記録: このディレクトリに YYYY-MM-DD-案件名.md で保存(_template.md使用)
6. 結果(返信/受注/見送られ)を追記 → 月次レビューのKPIファネルの元データになる
```

## なぜ「貼ってもらう」方式か

CWの募集一覧はログイン外から取得できない(外部アクセス遮断)。検索エンジンのインデックスは数ヶ月〜数年遅れで、生きた案件の確認には使えない。**ログイン済みアカウントの検索画面が唯一の一次情報源**のため、案件本文の持ち込みだけ人間が担い、判断材料の整理と提案文制作をClaudeが担う。
