# 副業計画書

作成日: 2026-07-04 / 次回見直し: 各月末(月次レビュー時)

## 1. 目的と制約

| 項目 | 内容 |
|---|---|
| 目的 | トレーディング(株式・暗号通貨)以外への収入源の分散。**稼ぐことが主目的** |
| 収入目標 | 月1〜3万円(手取りベース)。まず0→1の達成を最優先 |
| 稼働時間 | 週10時間未満。少ないほど良い |
| リソース | 実装・文章作成はClaudeに委任。人間の役割は判断・顧客対応・品質確認 |
| 初期投資 | 最小限(年間約2,000円のドメイン代のみ。詳細は§5) |

## 2. 戦略転換の経緯 — なぜアフィリエイト主軸をやめたか

当初はアフィリエイト+単発アプリを候補としていたが、リサーチの結果、**アフィリエイト単体は期待値が低い**と判断し格下げした。

- 実態調査では**月1万円未満が58.4%**、月5,000円未満が約52%。目標水準にすら届かない人が過半数([ブログ収入の現実](https://nondori.com/reality-of-blogging-income/))
- GoogleのAI Overview導入と、買い物リサーチのChatGPT/Gemini移行(利用率40〜45%)により、**記事へのクリックが構造的に減少中**([SEOアフィリエイトの現状分析](https://aferiburogu.com/seo%E3%80%80%E3%82%A2%E3%83%95%E3%82%A3%E3%83%AA%E3%82%A8%E3%82%A4%E3%83%88%E3%80%80%E7%B5%82%E3%82%8F%E3%82%8A/))
- 投資・金融ジャンルはYMYL領域で企業サイトが上位を独占。個人の後発参入は困難
- 成果発生まで6〜12ヶ月かかり、「稼ぐことが主目的」の条件と合わない

一方、**開発代行(GAS・スプレッドシート自動化)は市場が大きく即金性が高い**:

- クラウドワークスで「GAS」「スプレッドシート自動化」案件が**常時700〜1,000件、ボリュームゾーン5,000〜30,000円**([GAS開発代行の実態](https://note.com/thesaurus1/n/n73dc9d25fe10))
- 月5〜10時間の稼働で月3〜5万円の事例が多数([GAS副業ガイド](https://techgym.jp/fukugyo/gas/))
- Claudeに実装を任せれば1件あたりの実稼働は2〜4時間に圧縮できる

## 3. 戦略 — 2本柱+ついで

### 柱1: 開発代行(主軸。目標の約80%を担う)

- **領域**: GAS/スプレッドシート自動化、簡易スクレイピング、業務効率化スクリプト
- **プラットフォーム**: クラウドワークス+ランサーズ(能動応募)、ココナラ(出品して待ち受け)の併用
- **収益モデル**: 単価5,000〜30,000円 × 月1〜2件 = **月1〜3万円**
- **役割分担**: Claudeが実装・ドキュメント作成、人間は要件確認・納品・顧客対応
- 詳細手順: [freelance.md](freelance.md)

### 柱2: マイクロWebツール×広告(並走。資産化とポートフォリオ)

- 1機能のWebツールをClaudeで量産(1本2〜4時間)し、無料ホスティングに配置
- 収益化はAdSense(審査合格まで忍者AdMax)+文脈に合うアフィリエイトリンク
- **代行のポートフォリオを兼ねる**: 公開ツールが実績となり柱1の受注率を上げる
- 参考モデル(パクってアレンジする対象):
  - 文字数カウントメモ — ニッチ×圧倒的シンプル、広告収入累計700万円超([成功事例分析](https://shiftb.dev/articles/indie-dev-success-stories))
  - Pomofocus — ブラウザ完結+広告で収益の8割、サーバー費ほぼゼロ([収益化ロードマップ](https://shiftb.dev/articles/indie-dev-monetization))
  - オプチャグラフ — ニッチ統計の可視化、月6〜8万PVでAdSense月2万円前後([個人開発ルーティン](https://zenn.dev/uzuprg/articles/8b83ee58fc45bd))
- **収益レート前提**: AdSense ≒ 0.2〜0.5円/PV。月1万円には合計2〜5万PVが必要 → 1本で狙わずツール5〜10本で分散達成
- 詳細: [apps.md](apps.md) / 候補リスト: [ideas.md](ideas.md)

### アフィリエイト(ついで)

主軸にはしない。ツール・記事の文脈に自然に合う場合のみリンクを設置(もしも経由のAmazon/楽天、A8.net)。手順は [monetize.md](monetize.md)。

## 4. ロードマップ(3フェーズ)

### Phase 0: 立ち上げ(1ヶ月目 = 2026年7月)

- [ ] クラウドワークス・ランサーズ・ココナラに登録(すべて無料)
- [ ] プロフィール文・ポートフォリオページ整備
- [ ] 提案文テンプレート作成([freelance.md](freelance.md)参照)
- [ ] ポートフォリオ兼用ツール第1号を公開(ドメイン取得・ホスティング設定込み)
- [ ] **初受注1件**(小さくてよい。評価を1つ獲得することが目的)
- [ ] ココナラに出品ページを1つ作成

### Phase 1: ペース確立(2〜3ヶ月目)

- [ ] 代行を月1〜2件ペースに(→ 月1〜3万円ライン到達)
- [ ] 評価・実績を貯める(単価より評価優先の期間)
- [ ] ツールを2〜3本追加、GA4/Search Console計測開始
- [ ] ASP登録(A8.net・もしも)、忍者AdMax設置、AdSense申請

### Phase 2: 最適化(4〜6ヶ月目)

- [ ] 実績・評価を根拠に単価アップ、継続案件・リピーター化
- [ ] ツールはデータで判断: 伸びたものに追加投資、死んだものは放置
- [ ] ココナラ出品の拡充(定型メニュー化して待ちの受注を増やす)
- [ ] 月次レビューで柱1/柱2の時間配分を再調整

## 6. KPI

| 時期 | 目標 |
|---|---|
| 1ヶ月目 | 初受注1件・ツール1本公開 |
| 2ヶ月目 | 代行の受注ペース月1件以上・評価3件 |
| 3ヶ月目 | **月1〜3万円ライン到達**(代行主体) |
| 6ヶ月目 | 月2万円安定・AdSense稼働・ツール合計5,000PV/月 |
| 12ヶ月目 | 代行の単価上昇+ツール側+月5,000〜10,000円(労働依存度の低下) |

**撤退・調整基準**(月次レビューで判定):
- 代行: 3ヶ月連続で受注ゼロなら、提案文・出品内容・領域を全面見直し
- ツール: 公開後3ヶ月でPVが月100未満のものは追加投資しない(放置はOK、削除不要)
- 全体: 時給換算1,000円を下回る状態が3ヶ月続いたら戦略自体を再設計

## 7. リスクと注意事項

| リスク | 対策 |
|---|---|
| 就業規則・所属先の副業規定 | 開始前に確認する(特に本業/所属がある場合) |
| 納期遅延・炎上案件 | [freelance.md](freelance.md)の案件選定チェックリストを厳守。同時進行は2件まで |
| 税務 | 副業所得(雑所得)が**年20万円超で確定申告**が必要。20万円以下でも**住民税の申告は必要**。収支は月次レビューに記録して通年で把握 |
| 広告・ASP規約違反 | 自己クリック禁止・「広告」表記などの規約を[monetize.md](monetize.md)に集約し遵守 |
| AI生成コンテンツの品質 | 納品物・公開ツールは必ず人間が動作確認してから出す(信用が資産) |
| プラットフォーム依存 | CW/ランサーズ/ココナラを併用し、実績はポートフォリオサイトにも蓄積して可搬性を保つ |
