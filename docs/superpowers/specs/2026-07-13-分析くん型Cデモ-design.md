# 設計: 「分析くん」型Cデモ（Claude Amazon販売データ分析アプリ）

- 日付: 2026-07-13
- 対象案件: [CW 13301954](https://crowdworks.jp/public/jobs/13301954)（Claudeで国内Amazon販売データ分析アプリの大枠作成 / ¥1,500固定 / 継続依頼あり）
- 提案正本: [docs/proposals/2026-07-13-Claude-Amazon分析アプリ.md](../../proposals/2026-07-13-Claude-Amazon分析アプリ.md)

## 目的

評価0（Phase 0）の当方が応募条件「評価5件以上重視／実際にClaudeでアプリ作成できる方」を突破するための **型Cデモ**（[crowdworks.md](../../crowdworks.md) §4）。先に動くプロトタイプを作り、提案にスクショ/GIFを添付して「実績ゼロを一撃で無効化」する。CW上の送信は最後に人間が手動で行う。

## 成果物の形式

**単一の自己完結HTMLファイル**（inline JS/CSS・外部ライブラリ/CDN依存なし）。

- 根拠: 募集の核心が「納品後に私のClaude環境で継続修正できる形式でお渡しください」。単一HTMLならClaudeに貼って「この項目を追加して」で拡張でき、クライアントの継続修正要件そのものに一致する。React Artifactより手編集しやすい。
- 完成度は「8割の大枠」で可（募集も「必ずしも全部完璧に実装する必要はない」と明記）。

## データ取込

- 入力: Amazon JP セラーセントラル「全注文レポート」の実列を想定（TSV）。主に使う列:
  `purchase-date`（注文日時）/ `amazon-order-id` / `sku` / `asin` / `product-name` / `quantity-purchased` / `item-price`（＋通貨）。
- UI: ファイルのドラッグ&ドロップ＋テキスト貼り付けの両対応。区切りはタブ優先、カンマもフォールバック。
- **「サンプル読込」ボタン**: PCパーツ（マザーボード/メモリ/SSD/モニター 等）の約1年分リアル風ダミーデータを内蔵し、ワンクリックで全画面をデモ表示。実データが無くても提案デモが成立する。

## 分析ブロック（募集の5系統に対応）

1. **全体分析**: 該当ジャンルの販売商品数・ASIN数・総販売個数・総売上・平均販売価格・月別推移・多い/少ない月。
2. **メーカー分析**: 販売個数/売上ランキング・ASIN数・全体比率・安定販売・直近3/6か月の伸長。
3. **商品・型番分析**: 個数/売上ランキング・リピート販売/一度きりの判別・直近実績あり商品。
4. **仕入先分析**: SKU末尾コードから仕入先を判別し、仕入先別の個数/売上/売れ筋メーカー・型番。
5. **仕入れ判断サマリー**: 優先度が高そうなメーカー/型番/シリーズを要約提示。

ジャンル指定は商品名/SKUへのキーワード入力（例「マザーボード」）でフィルタ。

## 未知ルールを画面で可変にする（提案の差別化ポイント）

- **SKU末尾コード → 仕入先**: 実ルール未共有のため、「末尾N文字＝仕入先コード」の N と「コード→仕入先名」マップを **UI上で編集可能** にする。本番の実ルールに即応でき、提案で「ここは御社ルールに合わせます」と言える。
- **メーカー推定**: 商品名からのヒューリスティック抽出＋手動マップ可（Amazon全注文レポートにブランド列が無いケースに対応）。

## 描画

- 外部依存なしの **inline SVG** でチャート（月次: 棒/推移、ランキング: 横棒/表）。
- レイアウトはタブ or セクション積み。ダーク/ライト両対応は任意（デモは1テーマで可）。

## 配置

- `tools/analysis-kun-demo/index.html`（ポートフォリオ/デモ資産）。
- 補助データは同梱（ダミーはJS内リテラル）。README不要（提案添付が用途）。

## 非目標（YAGNI）

- 本番CSVスキーマへの完全対応（契約後に実データ共有 → その時点で微調整）。
- 永続化・ログイン・サーバー処理（全てブラウザ内完結）。
- 全分析項目の完璧な実装（大枠デモが目的）。

## 検証

- ブラウザプレビューで `index.html` を開く → 「サンプル読込」→ 各分析ブロックが表示されること、ジャンル入力でフィルタが効くこと、SKU末尾N/マップ変更が仕入先分析に反映されることを目視確認。スクショを取得。
