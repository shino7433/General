## 戦略サマリー

```
柱1(主軸・短期): 開発代行(GAS・スプレッドシート自動化)
  → 単価5,000〜30,000円 × 月1〜2件 = 月1〜3万円。初月から収益化可能

柱2(並走・中長期): マイクロWebツール × 広告
  → 制作物は代行のポートフォリオを兼ねる。6〜12ヶ月で+月5,000〜10,000円

アフィリエイト: ツール内に貼る「ついでのリンク」に格下げ
  → 単体では期待値が低い(月1万円未満が58.4%、AI Overviewの影響)ため主軸にしない
```
